🖥 面板设置

🔑 安全设置

📖 获取教程 & 时效说明
  1. 电脑：登录 x.com → F12 → Application → Cookies → 找到 auth_token 和 ct0，复制成 auth_token=值; ct0=值
  2. 手机（via 浏览器）：菜单 → 工具箱 → 查看 Cookie（或站点信息 → Cookie）→ 复制整条 Cookie 串
  3. 时效：约 1 年有效；重新登录/改密/被风控会提前失效，失效后重新获取
  4. 风险：抓评论为非常规访问，有封号风险，请使用小号，封号概不负责

🌐 代理配置

💡 怎么填？Windows / Linux 示例
  1. Clash 系（Win/Mac/Linux 通用）：保持 Clash 运行 → 填 http://127.0.0.1:7890（混合端口，推荐）或 socks5://127.0.0.1:7891
  2. v2rayN：填 http://127.0.0.1:10809（或设置里的 socks 端口）
  3. 仅开系统代理不够：curl / Node 抓取不认系统代理，必须填这里显式指定；填了外部代理就不会再启动内置 v2ray
  4. 本机已有代理服务（如 127.0.0.1:7891）：直接填对应地址即可；地址需要能访问 x.com
